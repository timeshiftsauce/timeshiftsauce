### 🌟 SyntaxSeed - 个人博客平台

> 为开发者打造的极简主义高端技术博客平台

**技术栈：** Vue 3 + TypeScript + Node.js + MySQL + Redis + Docker

**核心功能：**

- 🎨 现代化 UI 设计，支持深色/浅色主题
- 📱 响应式设计，完美适配各种设备
- 🚀 Redis 缓存加速，性能卓越
- 🔐 JWT 身份认证系统
- 📊 功能完善的管理后台
- 🐳 Docker 容器化部署
